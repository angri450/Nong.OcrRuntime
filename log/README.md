# Nong.OcrRuntime Log Archive

This directory is historical archive.

- `plans/` stores development plans.
- `changelog/` stores completed process/context notes.
- `debug/` stores investigation and failure notes.
- `guidance/` stores planning guidance.

Current state is `../PROJECT_STATE.md`. Only the plan linked from `../PROJECT_STATE.md` is active.

Runtime release notes may also live in root `CHANGELOG.md`.
